Act as a senior software architect, security engineer and QA engineer.

Review the current implementation of the application against:

1. project requirements
2. project context
3. architecture rules
4. database integrity
5. business rules
6. security requirements
7. RBAC
8. inventory integrity
9. financial integrity
10. offline synchronization
11. UX consistency
12. testing requirements

Do not modify the code immediately.

First inspect the implementation and produce:

- what is correct
- what is incomplete
- what is inconsistent
- what is dangerous
- what violates architecture
- what violates business rules
- what is over-engineered
- what is under-engineered
- missing tests
- security issues
- data integrity issues

Prioritize findings:

P0 = critical/blocking
P1 = high
P2 = medium
P3 = low

Then propose a remediation plan.

Wait for implementation instructions after producing the review.
