Currency: FCFA.

2. Return request
3. Return detail
4. Warranty lookup

- product
- IMEI 1
- IMEI 2
- serial number
- customer
- sale date
- warranty start
- warranty expiration
- warranty status
- sale reference

Return reasons:
- Produit défectueux
- Produit incorrect
- Client insatisfait
- Problème technique
- Autre

Return statuses:
- Demande
- En cours
- Accepté
- Refusé
- Remboursé
